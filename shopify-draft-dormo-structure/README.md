## Снимки (kie.ai)

`kie/generate_images.py` генерира 5 снимки с Nano Banana Pro, с реалните снимки на лепенката като референция:
`layers`, `nostomach`, `timeline`, `vs_patch`, `vs_capsules`.

```bash
export KIE_API_KEY=...
python3 kie/generate_images.py
```

Докато няма генерирани снимки, секциите показват съществуващи снимки от магазина. Всяка нова секция има поле „Снимка“ (избор от Files) и резервно поле с URL.
