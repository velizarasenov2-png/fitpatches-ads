# FitPatches — UGC 3D видео (пресъздадено)
### Скрипт + B-roll shot list · Жена на ~35 г. с наднормено тегло

Пресъздаване на реферативното видео (оригинал: анимирана реклама за крем против гъбички
`FUNGOMYCOL / INAessentials`, мъж на 58 г.) — **същата структура, ритъм и стил, но за FitPatches**
и с главна героиня **жена на около 35 години с наднормено тегло**.

## 1. Технически спецификации (както в оригинала)

| Параметър | Стойност |
|---|---|
| Формат | Вертикален **9:16**, 720×1280+ (Reels / TikTok / Shorts) |
| Дължина | ~58 секунди |
| Стил | **Pixar / 3D анимация**, топло осветление, меки материали, приятелски „cozy" интериори |
| Кадри в секунда | 24 fps |
| Субтитри | Големи **бели главни букви** с тънък контур, центрирани в долната трета (BG език) |
| Глас зад кадър (VO) | Женски, топъл, разказвачески, първо лице — „изповед" тон |
| Продукт на екрана | **FitPatches** — розова кръгла трансдермална лепенка + кутия (не крем/туба) |
| Приложение | Лепенка на **горната част на ръката**, върху чиста суха кожа |
| Активни съставки | **Берберин** (контролира апетита/грелина) + **Хром** (баланс на кръвната захар) |
| Метафора-механизъм | Двама мънички „войни" върху кожата/лепенката: зелен листен = берберин, кехлибарен кристал = хром |

**Структурата на хука е ключова** (както в оригинала): възраст + срам → тийзър на решението → история → механизъм → резултат → социално доказателство.

## 5. Продукшън бележки

- **Женски VO**, топъл разказвачески тон, темпо ~1 ред на 2 сек. Записвай по редовете от секция 2.
- **Консистентност на героинята:** генерирай първо S3 (уверено лице) като „master" референция и я подавай към всички останали кадри (image-to-video / character reference).

- **Субтитри:** бял Montserrat/Nunito Bold, главни букви, тънък тъмен контур + лека сянка; появяват се синхронно с VO.
