# FitPatches — промени в draft темата

Тези файлове са качени само в непубликуваната тема `theme-export-fitpatches-net-copy-of-copy-of-co` (ID 203774853457).
Активната тема не е променяна.

Преглед: https://fitpatches.net/products/fitpatches-berberinovi-plastiri-30?preview_theme_id=203774853457

Draft темата е копие на активната (снимки, секции, текстове, отзиви, Facebook коментари, лекар, начална страница).
Разликите са само тези:

| Файл | Промяна спрямо активния сайт |
|---|---|
| `snippets/fp-offer-v2.liquid` | Офертата от активния сайт, преместена в snippet. Пакети 1 / 2+1 подарък / 3+2 подарък (14,99 / 27,99 / 39,99 €) с цена на ден, 3+2 е избран по подразбиране. Без таймер и без зачеркната цена. Бързата поръчка (име + телефон) не води към checkout, а записва в Google таблица. |
| `snippets/fp-drawer.liquid` | Количката от активния сайт без лентата за безплатна доставка и без розовия бутон към checkout. Остава само бутонът на EasySell. Предложението в количката сменя пакета с 3+2. |
| `snippets/fp-thanks.liquid` | След поръчка през EasySell се показва „Благодарим за поръчката!“ без номер на поръчка. |
| `snippets/fp-header-style.liquid` | Лентата на хедъра е розова като лепенките (#f0c3dc). |
| `config/settings_data.json` | Новото лого `fitpatches-logo-2026.png` (в Shopify → Файлове) вместо `fitpatches_logo_nobg.png`. Размерът е същият: 120 px на компютър и 90 px на телефон. Всички други настройки са като на активния сайт. |
| `layout/theme.liquid` | Активният файл + двата snippet-а по-горе. |
| `templates/product.json` | Активният шаблон; блокът с офертата вика `fp-offer-v2`. |
| `templates/index.json` | Активната начална страница без „Безплатна доставка над 60 €“ (в банера и във въпросите). |
| `sections/fp-reviews.liquid` | Нова секция „Какво казват клиентите ни“ на мястото на Facebook макета (той е изключен, не е изтрит). Показва само истински коментари, добавени като блокове от редактора; без блокове не се вижда в сайта. |
| `sections/fp-*.liquid` (останалите), `sections/footer-group.json` | Същите като на активния сайт. |

## Google таблица

`google-sheets/Code.gs` е скриптът, който записва бързите поръчки. Инструкцията е в началото на файла.
След внедряване URL адресът `/exec` се слага в `snippets/fp-offer-v2.liquid` → `endpoint`.
Докато няма URL, формата казва на клиента да се обади на 0887 459 494.
