# Kie.ai — News Show Image (GPT Image / gptimage)

Генерира **вертикално 9:16** изображение на новинарска емисия:

- 🔵 синя тематика
- 🎭 стил на филма **ParaNorman** (stop-motion / claymation, LAIKA)
- 👤 **само един водещ — мъж**
- 🟦 четлив правоъгълник (chyron) с надпис: **„Решение за сладките изкушения“**

## Употреба

```bash
export KIE_API_KEY="твоят_ключ_от_kie.ai"
node generate.mjs
```

Изображението се записва като `news-paranorman-<timestamp>.png` в текущата папка.

## Настройки (по желание)

| Env променлива | По подразбиране | Описание |
|---|---|---|
| `KIE_API_KEY` | — | **Задължителен** API ключ от kie.ai |
| `KIE_MODEL` | `gpt-image-1` | Модел в Kie. Ако акаунтът ти листва GPT Image под друго име (напр. `openai/gpt-image-1`), сложи го тук. |
| `KIE_SIZE` | `2:3` | Съотношение/размер. GPT Image е портрет; 9:16 се подсилва и в самия промпт. |
| `OUT_DIR` | текущата папка | Къде да се запише файлът. |

## Как работи

1. `POST /api/v1/jobs/createTask` — създава задача с промпта.
2. Poll на `GET /api/v1/jobs/recordInfo?taskId=…` на всеки 5 сек, докато стане `success`.
3. Сваля готовото изображение локално.

> Забележка: GPT Image рендерира текст добре, но кирилицата понякога излиза с грешки.
> Ако надписът не е чист, пусни скрипта пак (промптът вече изисква точния текст в кавички
> и висок контраст за максимална четливост).
